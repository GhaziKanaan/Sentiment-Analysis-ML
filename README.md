# Sentiment Analysis ML

Machine learning research project focused on tweet sentiment classification using NLP and word embedding models.

---

## Overview

This research focuses on improving sentiment classification for tweets using natural language processing (NLP) and machine learning techniques.

The project applies word embedding methods such as Word2Vec and GloVe to improve semantic understanding and sentiment detection compared to traditional approaches like TF-IDF.

The dataset used in this research contains 4,546 tweets collected from Kaggle.

---

## Objectives

* Improve tweet sentiment classification accuracy
* Compare multiple machine learning models
* Apply NLP preprocessing techniques
* Evaluate word embedding performance in sentiment analysis

---

## Models Used

* Support Vector Machine (SVM)
* Logistic Regression
* Decision Tree
* Word2Vec
* GloVe

---

## NLP Preprocessing

The preprocessing pipeline includes:

* Text normalization
* Tokenization
* Stop-word removal
* Emoji removal
* Noise reduction

These preprocessing techniques improved sentiment classification performance and text quality.

---

## Results

Model performance comparison:

| Model                        | Accuracy |
| ---------------------------- | -------- |
| Support Vector Machine (SVM) | 87%      |
| Logistic Regression          | 85%      |
| Decision Tree                | 80%      |

The Support Vector Machine (SVM) achieved the highest classification accuracy.
